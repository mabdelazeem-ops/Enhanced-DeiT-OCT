# Enhanced DeiT for Patient-Stratified Retinal OCT Classification

Official codebase for the paper: **Data-efficient Image Transformer (DeiT) for High-Resolution Retinal OCT B-Scan Diagnostics**.

## 📌 Project Overview
This repository contains the TensorFlow implementation of the patient-stratified Data-efficient Image Transformer (DeiT) benchmarked against CNN baselines (ResNet-50, Inception-v3, DenseNet-40) using 20,061 macular OCT scans.
